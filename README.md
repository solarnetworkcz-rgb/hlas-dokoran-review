# Hlas Dokořán Studio - zákaznická kontrola

Statický web připravený pro GitHub Pages.

## Publikace

1. Vytvořit veřejný repozitář `hlas-dokoran-review`.
2. Nahrát celý obsah této složky do kořene repozitáře.
3. V GitHubu otevřít **Settings -> Pages**.
4. Zvolit **Deploy from a branch**, větev `main`, složku `/ (root)`.
5. Po uložení bude web na adrese přibližně:
   `https://solarnetworkcz-rgb.github.io/hlas-dokoran-review/`
